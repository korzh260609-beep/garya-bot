# SG 2.1 ROADMAP — BLOCK 10: DOMAIN MODULES

## Goal
Add optional product domains through stable platform contracts.

## Candidate domains
- documents
- repository analysis
- market analysis
- billing
- psychology support
- future Kingdom GARYA services

## Acceptance criteria
- Each domain uses capability, identity, memory, source and gate contracts.
- A domain cannot redefine Semantic Kernel, trust order, identity or Action Gate.
- Domain-specific data remains isolated by scope and permissions.
