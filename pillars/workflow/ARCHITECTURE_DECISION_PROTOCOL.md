# ARCHITECTURE DECISION PROTOCOL

A global architecture change requires:
1. Problem statement
2. Current constraint
3. Options considered
4. Trade-offs
5. Security, privacy and cost impact
6. Migration impact
7. Compatibility with SG identity
8. Explicit monarch approval
9. New or updated entry in `pillars/DECISIONS.md`
10. Synchronized architecture and roadmap updates

Implementation starts only after acceptance.
