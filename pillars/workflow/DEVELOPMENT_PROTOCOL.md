# DEVELOPMENT PROTOCOL

For every roadmap item:

1. Restore current project context.
2. Select one roadmap item.
3. Read governing decisions and architecture contracts.
4. Define scope, non-goals and acceptance criteria.
5. Create contracts and skeleton.
6. Add configuration and feature flags where required.
7. Implement minimal measurable logic.
8. Add contract, unit and integration tests.
9. Add observability and failure visibility.
10. Add permissions, idempotency, limits and confirmations where applicable.
11. Verify transport, model and storage independence.
12. Commit one reversible logical block.
13. Record factual evidence outside canonical architecture text.

Hard rule: skeleton → config → logic.
