# SG 2.1 WORKFLOW

This directory defines **how one selected roadmap item is implemented safely**. It does not repeat roadmap stages and does not store deployment history or runtime status.

## Authority

```text
DECISIONS → ARCHITECTURE → ROADMAP → WORKFLOW → CODE → TEST/RUNTIME EVIDENCE
```

## Files
1. `00_RULES_AND_ORDER.md` — universal development protocol
2. `01_STAGE_01_06_CORE.md` — change specification protocol
3. `02_STAGE_07_MEMORY.md` — test and evidence protocol
4. `03_STAGE_08_12_FOUNDATION.md` — release and rollback protocol
5. `04_STAGE_13_20_ADVANCED.md` — architecture decision protocol

## Boundaries
- Roadmap decides what comes next.
- Architecture defines contracts and boundaries.
- Workflow defines implementation procedure.
- Git history and dedicated reports contain historical facts.
- Pillars contain no manual completion markers.
